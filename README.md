# ABAP Cloud Project

This repository contains an ABAP Cloud project built following modern ABAP development paradigms, RAP (ABAP RESTful Application Programming Model), and cloud-ready extension principles.

## Features

* Modern ABAP development using ABAP Cloud syntax and restrictions
* Built with the ABAP RESTful Application Programming Model (RAP)
* Cloud-ready and upgrade-stable architecture

## Prerequisites

* SAP S/4HANA Cloud, public edition / private edition, or SAP BTP, ABAP Environment
* SAP ADT (ABAP Development Tools) in Eclipse

## Project Structure

* **Data Model:** Database tables, CDS views (Definition, Projection, Consumption)
* **Business Logic:** Behavior definitions, behavior implementations (CDS RAP)
* **Service Layer:** Service definitions and service bindings (OData V2 / V4)
